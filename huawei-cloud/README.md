## Training context

Huawei Cloud Solution Architecture training is ongoing. These exercises are practical learning activities completed in the training environment; completion of an individual lab does not imply completion of a certification exam.

## Documentation approach

Each lab distinguishes exercise objectives, demonstrated configuration, verification evidence, and remaining gaps. Credentials, active session tokens, and reusable authentication URLs must not be published. Sandbox account/resource identifiers and temporary public IP addresses should be assessed in context rather than automatically treated as credentials.
