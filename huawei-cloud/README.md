## Training context

Huawei Cloud Solution Architecture training is ongoing. The exercises in this directory are practical learning activities completed in the training environment; completion of an individual lab does not imply completion of a certification exam.

## Documentation approach

Each lab is documented with its objective, services, architecture, implementation outline, verification approach, and operational considerations. Evidence links are included where screenshots are available. Original cloud-console screenshots must be checked for account identifiers, public IP addresses, resource IDs, and session information before public release.
