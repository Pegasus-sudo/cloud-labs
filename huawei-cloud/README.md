# Huawei Cloud Labs

Hands-on exercises completed as part of Huawei Cloud learning and Solution Architecture training. The documentation focuses on the configuration, connectivity, and operational behavior of core cloud services.

> These entries document training exercises and lab environments. They are not claims of production deployments or Huawei certifications.

## Training context

Huawei Cloud Solution Architecture training is ongoing. The exercises in this directory are practical learning activities completed in the training environment; completion of an individual lab does not imply completion of a certification exam.

## Documentation approach

Each lab is documented with its objective, services, architecture, implementation outline, verification approach, and operational considerations. Architecture and evidence are included where they are available and verified.
