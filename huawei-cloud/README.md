## Training context

Huawei Cloud Solution Architecture training is ongoing. These exercises are practical learning activities completed in the training environment; completion of an individual lab does not imply completion of a certification exam.

## Documentation approach

Each lab distinguishes exercise objectives, demonstrated configuration, verification evidence, and remaining gaps. Original cloud-console screenshots must be checked for account identifiers, public IP addresses, resource IDs, and session information before public release.
